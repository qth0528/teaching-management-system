**关系说明：**

| 子表（多端） | 关联字段 | 父表（一端） | 关系 |
|-------------|---------|-------------|------|
| teacher | user_id | user | 一个用户对应一位教师（1:1） |
| class | teacher_id | teacher | 一位教师负责多个班级（1:N） |
| student | class_id | class | 一个班级包含多个学生（1:N） |
| schedule | class_id | class | 一个班级有多条排课记录（1:N） |
| schedule | course_id | course | 一门课程出现在多条排课中（1:N） |
| schedule | teacher_id | teacher | 一位教师有多条排课记录（1:N） |
| attendance | student_id | student | 一个学生有多条考勤记录（1:N） |
| attendance | class_id | class | 一个班级有多条考勤记录（1:N） |
| score | student_id | student | 一个学生有多条成绩记录（1:N） |
| score | class_id | class | 一个班级有多条成绩记录（1:N） |
| score | course_id | course | 一门课程有多条成绩记录（1:N） |
| homework | class_id | class | 一个班级有多次作业（1:N） |
| homework | course_id | course | 一门课程有多次作业（1:N） |
| homework | teacher_id | teacher | 一位教师发布多次作业（1:N） |
| homework_submission | homework_id | homework | 一次作业有多条提交记录（1:N） |
| homework_submission | student_id | student | 一个学生有多条提交记录（1:N） |

## 二、建表 SQL

### 2.1 用户表 `user`

存储登录账号信息，用于系统身份认证。

```sql
CREATE TABLE `user` (
  `id`              BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `username`        VARCHAR(50)  NOT NULL                COMMENT '用户名',
  `password`        VARCHAR(255) NOT NULL                COMMENT '密码（加密存储）',
  `status`          TINYINT      NOT NULL DEFAULT 1      COMMENT '账号状态：1=正常，0=锁定',
  `login_fail_count` INT         NOT NULL DEFAULT 0      COMMENT '连续登录失败次数',
  `locked_until`    DATETIME     DEFAULT NULL            COMMENT '锁定截止时间',
  `last_login_time` DATETIME     DEFAULT NULL            COMMENT '最后登录时间',
  `create_time`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`      TINYINT      NOT NULL DEFAULT 0      COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
```

### 2.2 教师表 `teacher`

存储教师基本信息，与登录账号一对一关联。

```sql
CREATE TABLE `teacher` (
  `id`          BIGINT      NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `user_id`     BIGINT      NOT NULL                COMMENT '关联用户ID',
  `teacher_no`  VARCHAR(30) NOT NULL                COMMENT '教师编号',
  `name`        VARCHAR(50) NOT NULL                COMMENT '教师姓名',
  `gender`      TINYINT     NOT NULL DEFAULT 0      COMMENT '性别：1=男，2=女',
  `phone`       VARCHAR(20) DEFAULT NULL            COMMENT '手机号',
  `create_time` DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`  TINYINT     NOT NULL DEFAULT 0      COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='教师表';
```

### 2.3 班级表 `class`

存储班级信息，每个班级指定一位负责教师。

```sql
CREATE TABLE `class` (
  `id`          BIGINT      NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `class_name`  VARCHAR(50) NOT NULL                COMMENT '班级名称',
  `teacher_id`  BIGINT      NOT NULL                COMMENT '负责教师ID',
  `room_number` VARCHAR(30) DEFAULT NULL            COMMENT '教室编号',
  `create_time` DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`  TINYINT     NOT NULL DEFAULT 0      COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='班级表';
```

### 2.4 学生表 `student`

存储学生基本信息，每个学生归属于一个班级。

```sql
CREATE TABLE `student` (
  `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `student_no`  VARCHAR(30)  NOT NULL                COMMENT '学号',
  `name`        VARCHAR(50)  NOT NULL                COMMENT '学生姓名',
  `gender`      TINYINT      NOT NULL DEFAULT 0      COMMENT '性别：1=男，2=女',
  `class_id`    BIGINT       NOT NULL                COMMENT '所属班级ID',
  `phone`       VARCHAR(20)  DEFAULT NULL            COMMENT '手机号',
  `address`     VARCHAR(255) DEFAULT NULL            COMMENT '家庭住址',
  `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`  TINYINT      NOT NULL DEFAULT 0      COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='学生表';
```

### 2.5 课程表 `course`

存储课程（科目）定义，一门课程可被排入多个班级的课表。

```sql
CREATE TABLE `course` (
  `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `course_name` VARCHAR(50)  NOT NULL                COMMENT '课程名称',
  `full_score`  DECIMAL(5,1) NOT NULL DEFAULT 100.0  COMMENT '满分值',
  `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`  TINYINT      NOT NULL DEFAULT 0      COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='课程表';
```

### 2.6 排课表 `schedule`

存储班级每周课表安排，每条记录表示某班在某个时间段上某门课。

```sql
CREATE TABLE `schedule` (
  `id`           BIGINT      NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `class_id`     BIGINT      NOT NULL                COMMENT '班级ID',
  `course_id`    BIGINT      NOT NULL                COMMENT '课程ID',
  `teacher_id`   BIGINT      NOT NULL                COMMENT '授课教师ID',
  `day_of_week`  TINYINT     NOT NULL                COMMENT '星期：1=周一，2=周二，3=周三，4=周四，5=周五',
  `period`       TINYINT     NOT NULL                COMMENT '节次：1~8',
  `room_number`  VARCHAR(30) DEFAULT NULL            COMMENT '上课教室',
  `semester`     VARCHAR(30) NOT NULL                COMMENT '学期（如2025-2026-1）',
  `create_time`  DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`  DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`   TINYINT     NOT NULL DEFAULT 0      COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='排课表';
```

### 2.7 考勤表 `attendance`

存储每日学生出勤记录，每天每个学生仅一条记录。

```sql
CREATE TABLE `attendance` (
  `id`              BIGINT   NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `student_id`      BIGINT   NOT NULL                COMMENT '学生ID',
  `class_id`        BIGINT   NOT NULL                COMMENT '班级ID（冗余，便于按班级查询）',
  `attendance_date` DATE     NOT NULL                COMMENT '考勤日期',
  `status`          TINYINT  NOT NULL DEFAULT 1      COMMENT '考勤状态：1=出勤，2=迟到，3=请假，4=缺勤',
  `create_time`     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`      TINYINT  NOT NULL DEFAULT 0      COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='考勤表';
```

### 2.8 成绩表 `score`

存储学生各科考试成绩，缺考时 score 为 NULL。

```sql
CREATE TABLE `score` (
  `id`          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `student_id`  BIGINT       NOT NULL                COMMENT '学生ID',
  `class_id`    BIGINT       NOT NULL                COMMENT '班级ID（冗余，记录考试时所在班级）',
  `course_id`   BIGINT       NOT NULL                COMMENT '课程ID',
  `exam_name`   VARCHAR(100) NOT NULL                COMMENT '考试名称（如"第一次月考"）',
  `exam_type`   TINYINT      NOT NULL DEFAULT 5      COMMENT '考试类型：1=月考，2=期中，3=期末，4=模拟考，5=其他',
  `score`       DECIMAL(5,1) DEFAULT NULL            COMMENT '分数，NULL表示缺考',
  `exam_date`   DATE         NOT NULL                COMMENT '考试日期',
  `create_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`  TINYINT      NOT NULL DEFAULT 0      COMMENT '逻辑删除：0=未删除，1=已删除',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='成绩表';
```

### 2.9 作业表 `homework`

存储教师发布的作业信息。

```sql
CREATE TABLE `homework` (
```

### 2.10 作业提交表 `homework_submission`

存储学生对作业的提交记录和批改结果。

```sql
CREATE TABLE `homework_submission` (
  `id`          BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键ID',
```

## 三、索引设计

### 3.1 `user` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `uk_username` | `username` | 唯一索引 | 用户名必须全局唯一，登录时按用户名查询，需唯一约束 + 快速查找 |

### 3.2 `teacher` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `uk_teacher_no` | `teacher_no` | 唯一索引 | 教师编号全局唯一 |
| `idx_user_id` | `user_id` | 普通索引 | 通过用户ID反查教师信息，登录后获取教师身份 |

### 3.3 `class` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `uk_class_name` | `class_name` | 唯一索引 | 班级名称全局唯一（需求要求"班级名称必须唯一"） |
| `idx_teacher_id` | `teacher_id` | 普通索引 | 按负责教师查询其管理的班级列表 |

### 3.4 `student` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `uk_student_no` | `student_no` | 唯一索引 | 学号全局唯一（需求要求"学号必须唯一"） |
| `idx_class_id` | `class_id` | 普通索引 | 按班级筛选学生列表，是最高频的查询条件之一 |
| `idx_name` | `name` | 普通索引 | 按姓名模糊搜索，前端搜索框使用频率高 |

### 3.5 `course` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `uk_course_name` | `course_name` | 唯一索引 | 课程名称全局唯一，防止重复录入同一科目 |

### 3.6 `schedule` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `idx_class_semester` | `class_id, semester` | 联合索引 | 按班级+学期查询课表，是最核心的查询场景 |
| `uk_class_time` | `class_id, day_of_week, period, semester` | 唯一联合索引 | **冲突检测**：同一班级同一时间段不能排两门课 |
| `uk_teacher_time` | `teacher_id, day_of_week, period, semester` | 唯一联合索引 | **冲突检测**：同一教师同一时间段不能上两门课 |
| `uk_room_time` | `room_number, day_of_week, period, semester` | 唯一联合索引 | **冲突检测**：同一教室同一时间段不能安排两门课 |

### 3.7 `attendance` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `uk_student_date` | `student_id, attendance_date` | 唯一索引 | 每天每个学生仅一条考勤记录（需求要求） |
| `idx_class_date` | `class_id, attendance_date` | 联合索引 | 按班级+日期查询全班出勤情况，是考勤模块最高频查询 |
| `idx_attendance_date` | `attendance_date` | 普通索引 | 按日期范围做考勤统计（如近7天趋势图） |

### 3.8 `score` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `uk_student_exam_course` | `student_id, exam_name, course_id` | 唯一索引 | 同一学生在同一次考试中同一科目仅一条成绩（需求要求） |
| `idx_class_course` | `class_id, course_id` | 联合索引 | 按班级+科目筛选成绩列表 |
| `idx_student_id` | `student_id` | 普通索引 | 按学生查询其所有成绩 |
| `idx_exam_name` | `exam_name` | 普通索引 | 按考试名称做成绩统计（最高分、最低分、平均分） |

### 3.9 `homework` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `idx_class_id` | `class_id` | 普通索引 | 按班级筛选作业列表 |
| `idx_teacher_id` | `teacher_id` | 普通索引 | 按教师筛选其发布的作业 |
| `idx_deadline` | `deadline` | 普通索引 | 查询即将到期的作业，用于催交提醒 |

### 3.10 `homework_submission` 表索引

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| `uk_homework_student` | `homework_id, student_id` | 唯一索引 | 同一学生对同一作业仅一条提交记录 |
| `idx_homework_status` | `homework_id, status` | 联合索引 | 查看某作业的整体提交情况（已提交/未批改），仪表盘"待批改作业数"依赖此索引 |
| `idx_student_id` | `student_id` | 普通索引 | 按学生查询其所有作业提交记录 |

## 四、索引设计原则总结

| 原则 | 应用 |
|------|------|
| **唯一约束 = 唯一索引** | 所有唯一业务字段（学号、班级名称、用户名等）均建唯一索引，兼顾约束和数据完整性 |
| **高频 WHERE 条件建索引** | 如 `class_id`、`student_id`、`attendance_date` 等高频查询字段 |
| **冲突检测用联合唯一索引** | `schedule` 表的教师/教室/班级三重冲突检测，各用一个联合唯一索引实现 |
| **冗余字段服务于查询效率** | `attendance.class_id` 和 `score.class_id` 是冗余字段，避免连表查询，提升统计性能 |
| **避免过度索引** | 低频查询字段（如 `gender`、`address`）不建索引，减少写入开销 |
