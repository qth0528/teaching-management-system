## 阶段一：前端公共基础设施（任务 1~4）

> 目标：搭建前端骨架，后续所有页面依赖此阶段完成。

---

  | 项目 | 内容 |
  |------|------|
  | **任务内容** | 在 `front/` 下创建 `css/`、`js/`、`js/pages/` 三个子目录。编写 `css/style.css`，定义全局样式：body 背景色、侧边栏宽度(220px)、主内容区边距、卡片样式、表格样式、按钮间距、统一字体等。 |

  | **验收标准** | 在浏览器中打开任意引入了 `style.css` 的 HTML 页面，页面背景色和字体生效，无 404 错误 |

  | **涉及文件** | `front/js/common.js` |
  | **前置依赖** | 无 |
  | **验收点** | 1/4 request 函数可发起 GET/POST/PUT/DELETE 请求 2/4 请求自动附带 `/api/` 前缀 3/4 token 自动从 localStorage 读取并注入请求头 4/4 枚举映射函数返回正确的中文文本 |
  | **验收标准** | 在浏览器控制台调用 `request('/test')`，能正确发起网络请求；调用 `formatDate(new Date(), 'YYYY-MM-DD')` 返回正确格式的日期字符串 |
