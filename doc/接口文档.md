# 教学数字平台管理系统 —— 接口文档

## 文档信息

| 项目 | 内容 |
|------|------|
| 项目名称 | 教学数字平台管理系统 |
| 版本 | V1.0 |
| 接口前缀 | `/api/` |
| 请求格式 | JSON（Content-Type: application/json） |
| 响应格式 | `{ "code": 200, "message": "success", "data": {} }` |

---

## 一、通用说明

### 1.1 统一返回格式

**成功响应：**

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

**失败响应：**

```json
{
  "code": 400,
  "message": "具体错误信息",
  "data": null
}
```

### 1.2 业务状态码

| code | 含义 |
|------|------|
| 200 | 操作成功 |
| 400 | 请求参数错误（前端校验失败） |
| 401 | 未登录或登录已过期 |
| 403 | 账号已被锁定 |
| 404 | 资源不存在 |
| 409 | 数据冲突（如学号重复、班级名称重复） |
| 500 | 服务器内部错误 |

### 1.3 列表查询通用约定

- 请求参数：`page`（第几页，从 1 开始）、`pageSize`（每页条数，默认 20）
- 返回格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "list": []
  }
}
```

### 2.1 用户登录

| 项目 | 内容 |
|------|------|
| **用途** | 验证用户名和密码，登录系统 |

```json
  "message": "登录成功",

      "teacherName": "张老师"

```

```json
{
  "code": 400,

  "data": null
}
```

```json

  "code": 403,
```
