## 1. 登录模块

### 1.1 功能说明
为系统提供安全的身份认证，确保只有合法用户才能访问系统功能。

### 1.2 用户操作
| 操作 | 描述 |
|------|------|
| 登录 | 用户输入用户名和密码，点击"登录"按钮进入系统 |
| 退出 | 已登录用户点击"退出登录"，清除登录状态，返回登录页 |

### 1.3 业务规则
- 用户名和密码均为必填项，不能为空
- 密码输入框内容需掩码显示（显示为 `***`）
- 登录失败时提示"用户名或密码错误"，不区分是用户名错误还是密码错误
- 连续登录失败 5 次后，账号锁定 30 分钟
- 登录成功后跳转至仪表盘页面
- 未登录状态下访问任何系统页面，自动跳转到登录页

### 1.4 特殊情况
- 用户长时间无操作（30 分钟）后，会话自动过期，需重新登录
- 同一账号不允许在多处同时登录（后登录的会话踢掉先登录的会话）
- 浏览器关闭后重新打开，会话已失效，需重新登录

## 2. 仪表盘模块

### 2.1 功能说明
登录后的首页，以图表和统计卡片的形式直观展示教学数据概况，帮助管理者快速掌握全局信息。

### 2.2 用户操作
| 操作 | 描述 |
|------|------|
| 查看统计卡片 | 查看学生总数、班级总数、今日出勤率、待批改作业数四张统计卡片 |
| 查看班级分布图 | 查看各班级学生人数分布柱状图或饼图 |
| 查看出勤趋势图 | 查看近 7 天出勤率变化趋势折线图 |
| 快捷跳转 | 点击统计卡片可跳转到对应的管理页面 |

### 2.3 业务规则
- 仪表盘数据为实时统计，每次进入页面或刷新时重新计算
- 今日出勤率 =（今日出勤人数 / 应到总人数）× 100%，保留一位小数
- 待批改作业数 = 已提交但未批改的作业总数
- 近 7 天出勤趋势图以天为横坐标，出勤率为纵坐标

### 2.4 特殊情况
- 系统首次使用无任何数据时，统计卡片显示 0，图表区域显示"暂无数据"占位提示
- 某天无任何考勤记录时，该天出勤率不参与趋势图绘制（跳过，不显示为 0）
- 数据量较大时，仪表盘数据需做缓存，5 分钟内不重复查询数据库

## 3. 学生管理模块

### 3.1 功能说明
维护学生基础信息，支持对学生的增删改查操作，以及按条件检索和翻页浏览。

### 3.2 用户操作
| 操作 | 描述 |
|------|------|
| 查询学生 | 按姓名模糊搜索、按班级下拉筛选，结果以表格展示，支持翻页 |
| 新增学生 | 点击"新增"按钮，弹出表单填写学生信息并保存 |
| 修改学生 | 在表格中点击某行的"编辑"按钮，弹出表单修改信息并保存 |
| 删除学生 | 在表格中点击某行的"删除"按钮，确认后删除 |
| 批量导入 | 支持通过 Excel 文件批量导入学生信息（可选功能） |

### 3.3 业务规则
- 一个学生只能属于一个班级
- 学生字段至少包含：姓名、学号、性别、班级、手机号、家庭住址
- 学号必须唯一，系统自动校验重复
- 手机号格式需校验（11 位数字）
- 姓名和学号为必填项
- 删除学生为逻辑删除（标记 `is_deleted = 1`），不从数据库中物理删除
- 翻页默认每页显示 20 条记录

### 3.4 特殊情况
- 删除学生前需二次弹窗确认
- 如果学生有未批改的作业或关联的考勤记录，删除时需提示："该学生存在关联数据（考勤记录 X 条、作业记录 X 条），确定删除吗？"
- 学号重复时，保存失败并提示"学号已存在"
- 搜索无结果时，表格显示"暂无数据"

## 4. 班级管理模块

### 4.1 功能说明
维护班级基础信息，每个班级指定一名教师作为负责老师，支持班级的增删改查。

### 4.2 用户操作
| 操作 | 描述 |
|------|------|
| 查询班级 | 按班级名称模糊搜索，结果以表格展示，支持翻页 |
| 新增班级 | 点击"新增"按钮，填写班级信息（名称、负责老师、教室等） |
| 修改班级 | 点击"编辑"按钮，修改班级信息（允许更换负责老师） |
| 删除班级 | 点击"删除"按钮，确认后删除 |
| 查看班级学生 | 点击班级名称，查看该班级下的学生列表 |

### 4.3 业务规则
- 班级字段至少包含：班级名称、负责老师、教室编号、学生人数
- 班级名称必须唯一
- 每个班级有且仅有一位负责老师
- 一位老师可以负责多个班级
- 学生人数为系统自动统计（该班级下未删除的学生数量），不可手动修改
- 删除班级为逻辑删除

### 4.4 特殊情况
- **删除班级前必须检查**：若班级下存在未删除的学生，禁止删除，提示："该班级下还有 X 名学生，请先将学生移出班级后再删除"
- 班级名称重复时，保存失败并提示"班级名称已存在"
- 修改班级时，如果将负责老师设为空，提示"请选择负责老师"
- 班级删除后，该班级关联的排课数据同步标记为无效

## 5. 课程排课模块

### 5.1 功能说明
为班级安排课程表，以周课表表格的形式直观展示每个班级每天的上课安排。

### 5.2 用户操作
| 操作 | 描述 |
|------|------|
| 查看课表 | 选择班级和学期/周次，以表格查看该班级一周课表 |
| 添加课程 | 在课表指定格子（星期 × 节次）中添加一门课程 |
| 修改课程 | 修改已安排课程的信息（课程名称、教师、教室等） |
| 删除课程 | 删除课表中某门课程 |
| 批量排课 | 支持按模板快速复制一周课表到指定周次 |

### 5.3 业务规则
- 课表以表格形式展示：行为节次（第1节~第8节），列为星期（周一~周五）
- 每个课程包含：课程名称、授课教师、上课教室
- 同一教师在同一个时间段（星期 + 节次）不能安排两门课程
- 同一教室在同一个时间段不能安排两门课程
- 同一班级在同一个时间段不能安排两门课程

### 5.4 特殊情况
- 课表冲突检测：排课时若教师/教室/班级有时间冲突，提示具体的冲突信息（如"张老师在周一第3节已有课程"）
- 排课时如果选择的班级已被删除（逻辑删除），提示"该班级已不存在"
- 课表打印/导出：支持将课表导出为 Excel 或直接打印

## 6. 考勤打卡模块

### 6.1 功能说明
每日记录学生的出勤情况，支持四种考勤状态的管理和统计。

### 6.2 用户操作
| 操作 | 描述 |
|------|------|
| 查看考勤 | 按日期和班级查看某天某班所有学生的出勤状态列表 |
| 录入考勤 | 逐条或批量设置学生的出勤状态（出勤/迟到/请假/缺勤） |
| 修改考勤 | 修改某条已录入的考勤记录 |
| 一键全勤 | 一键将全班当天出勤状态设为"出勤"，再手动调整异常学生 |
| 考勤统计 | 按班级、日期范围统计出勤率、迟到率等 |

### 6.3 业务规则
- 考勤状态包含四种：**出勤**、**迟到**、**请假**、**缺勤**
- 每天每个学生只有一条考勤记录（日期 + 学生 = 唯一）
- 出勤率 =（出勤人数 / 班级总人数）× 100%
- 考勤记录一旦保存，当日不可删除（只能修改状态）
- 当天只能录入当天的考勤，不允许补录过去日期的考勤（管理员可例外）
- 默认状态下所有学生为"出勤"

### 6.4 特殊情况
- 如果某学生已从班级删除但历史考勤记录仍保留，考勤统计时过滤掉已删除学生
- 非工作日（周末、节假日）不要求录入考勤，进入考勤页面时提示"今日为非工作日"
- 当天已录入的考勤再次进入时直接展示已有记录，避免重复录入
- 批量操作时，如果部分学生当天已有考勤记录，自动跳过（不覆盖已有记录），完成后给出提示

## 7. 成绩管理模块

### 7.1 功能说明
教师录入和管理学生的各科考试成绩，支持按学生和科目多维度查询成绩。

### 7.2 用户操作
| 操作 | 描述 |
|------|------|
| 录入成绩 | 选择班级、科目、考试名称，录入班上每个学生的分数 |
| 修改成绩 | 修改已录入的学生成绩 |
| 查询成绩 | 按学生姓名搜索、按班级筛选、按科目筛选，展示成绩列表 |
| 成绩统计 | 展示某次考试的最高分、最低分、平均分、及格率 |
| 导出成绩 | 将成绩数据导出为 Excel 文件 |

### 7.3 业务规则
- 成绩字段至少包含：学生、班级、科目、考试名称、分数、考试日期
- 分数范围为 0~300（不同科目满分可能不同，由科目设置决定）
- 成绩录入时需选择考试类型（如：月考、期中、期末、模拟考等）
- 同一学生在同一考试中，同一科目只能有一条成绩记录
- 成绩修改需记录修改人和修改时间
- 及格分数线默认为满分的 60%

### 7.4 特殊情况
- 学生转班后，历史成绩仍保留在原班级维度下，不随学生迁移
- 某个学生缺考时，成绩栏可设为"缺考"而非 0 分，"缺考"不计入平均分和及格率统计
- 分数为负数或远超满分时，保存失败并提示"请输入 0~满分值 之间的分数"
- 已删除学生的历史成绩仍然保留并可查询

## 8. 作业管理模块

### 8.1 功能说明
教师在线发布作业，学生（或由教师代为）提交作业，教师批改打分，形成完整的作业管理闭环。

### 8.2 用户操作
| 操作 | 描述 |
|------|------|
| 发布作业 | 教师选择班级、科目，填写作业标题、内容描述、截止时间，发布作业 |
| 查看作业列表 | 按班级和科目筛选查看已发布的作业列表 |
| 提交作业 | 学生或教师上传作业文件或填写文本内容，标记完成状态 |
| 批改作业 | 教师查看学生提交的作业内容，打分并填写评语 |
| 查看提交情况 | 查看某次作业的整体提交情况（已提交 X 人 / 未提交 X 人） |
| 催交提醒 | 对未提交学生发送提醒通知 |

### 8.3 业务规则
- 作业字段至少包含：标题、内容描述、班级、科目、发布时间、截止时间
- 作业提交记录字段至少包含：作业ID、学生ID、提交内容、提交时间、分数、评语、批改状态
- 批改状态分为：**未提交**、**已提交待批改**、**已批改**
- 超过截止时间后，作业提交状态标记为"迟交"
- 分数范围为 0~100
- 教师只能看到自己发布或自己班级的作业

### 8.4 特殊情况
- 删除作业前，提示"该作业下有 X 条提交记录，删除作业将同步删除所有提交记录，确定删除吗？"
- 截止时间必须晚于发布时间，否则提示"截止时间必须晚于发布时间"
- 某学生已从班级删除，该学生历史提交的作业记录仍保留
- 作业提交情况页面（仪表盘统计卡片的数据来源）需显示"待批改"状态的作业数量

## 附录：通用业务规则

### A. 数据表规范
- 每张数据表必须包含字段：`id`（主键）、`create_time`（创建时间）、`update_time`（更新时间）、`is_deleted`（逻辑删除标记）
- 删除操作统一使用逻辑删除（`is_deleted = 1`），不做物理删除

### B. 接口规范
- 所有接口返回统一格式：`{ "code": 200, "message": "success", "data": {} }`
- 接口地址统一以 `/api/` 开头
- 后端接口必须做参数校验，前端表单必须做输入校验

### C. 权限约定（V1.0 简化）
- 当前版本暂不区分管理员和教师角色，登录用户拥有全部功能权限
- 后续版本可扩展角色权限体系（管理员、教师、学生/家长）

### D. 数据字典参考

| 字段 | 类型 | 说明 |
|------|------|------|
| 出勤状态 | 枚举 | 出勤、迟到、请假、缺勤 |
| 考试类型 | 枚举 | 月考、期中、期末、模拟考、其他 |
| 批改状态 | 枚举 | 未提交、已提交待批改、已批改 |
| 性别 | 枚举 | 男、女 |
